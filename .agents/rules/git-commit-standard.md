# RetainIQ Git Commit Standard

Before creating any Git commit:

1. Read and follow `docs/GIT_COMMIT_STANDARD.md`.
2. Inspect the actual Git status and complete relevant diffs.
3. Build the commit message from verified changes.
4. Use the required subject and structured body.
5. Report tests accurately.
6. Do not commit unrelated files.
7. Never push without authorization.
